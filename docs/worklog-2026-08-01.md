## 2. 수정 내역

### 복사 기능 (사용자 리포트로 시작)

- `ui.js`에 공용 `copyText()` 신설 — Clipboard API 실패·부재 시 readonly textarea + `execCommand('copy')` 폴백.
  카카오톡·네이버 등 **인앱 브라우저에서 복사가 무음 실패하던 문제 해소**. 호출부 4곳(허브·조 배정×2·로또) 교체.
- 로또 공유: `AbortError`(사용자 취소)만 무시하고, 공유 차단 환경은 클립보드 폴백으로 — 무반응 종료 제거.

### 높음 (기능 고장·크래시)

| 대상 | 내용 |
|---|---|
| 룰렛 | 더블탭 예열 660ms 동안 `lock()` — 스핀 직전 편집으로 인한 결과 공개 크래시·영구 잠금 경로 봉쇄 |
| 조 배정 | 지난 편성 복원이 조 수를 인원 상한 위로 되올리던 것 차단(배정 불가 고착 해소) + 경고 문구가 지난 편성 요약으로 복귀(`showLastSummary`) |
| 로또 | 복사·공유가 화면에 보이는 줄 수(`lineCount`)까지만 포함 — 표시와 복사 결과 일치 |
| index.html | 입력 필드에 `-webkit-touch-callout: default` 복원 — iOS 길게 눌러 붙여넣기 차단 해소 |
| 허브 | iPadOS 13+ 판정(`Macintosh` + `maxTouchPoints`) — 존재하지 않는 설치 경로 안내 수정 |
| privacy.html | localStorage 고지에 빙고 2종 추가, 시행일 2026-08-01 갱신, sitemap lastmod 동기화 |

### 중간 (특정 환경·순서에서 오동작)

| 대상 | 내용 |
|---|---|
| 빙고 2종 | 두 번 탭 확정 타이머 초기값 `0` → `-Infinity` (기동 1.6초 안 첫 탭이 확정으로 오인) + 확정 시 토스트 복원 무효화 |
| 빙고판 | 설정 변경 후 주 버튼 라벨('끝!') 갱신 |
| 로또 | `toastHint` 원본 최초 1회 캡처 — 중첩 시 확률 고지 라인이 지워지던 문제 해소 |
| 사다리 | `flashHint` 복귀 문구를 발화 시점 상태로 계산(거짓 안내 제거) |
| 뽑기 상자 | 재진입 `editor` stale 초기화(편집이 영영 안 열림) + `flashHint`의 토스트 복원 무효화 + onDone 가드 |
| 악어 | 리셋 시 위턱 트윈 정리(새 판 위 잔상 제거) |
| 단청 | 빈 캔버스 탭만 자판 내리기 — 자판 열린 채 '묻기' 탭이 삼켜지던 문제 해소 |
| 핀볼 | 칩 재렌더마다 카메라 재지정(이중 렌더 방지) + onDone 가드 |
| 자판/iOS | 입력 오버레이·붙여넣기 닫을 때 `blur()` 선행, 붙여넣기 오버레이에 딤 차단막(모달 문법 통일) |
| 인앱/PWA | 설치 안내에 "다른 브라우저로 열기" 분기, 크레딧 링크 팝업 차단 토스트, iOS 16.4 미만 `navigator.standalone` 병행 감지 |
| 성능 | 허브 QR을 최초 1회 텍스처로 구워 표시(매 프레임 Graphics 재처리 제거) |
| 정적 페이지 | nav·footer 링크 터치 타깃 약 26px → 약 46px, `#game`에 `touch-action: manipulation` |

검토 결과 **수정하지 않은 건**: 핀볼 드래그 릴리스 vs 버튼 충돌 의혹 — `release`가 `follow()` 전에 `locked`를 검사해 실제로는 안전함을 확인.
